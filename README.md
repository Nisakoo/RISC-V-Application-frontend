# Лабораторная работа №5

**Цель работы**: разработка базового SPA на React.

**Порядок показа**: **Скриншоты 1-3** Показать три страницы фронтенда с `mock` и вкладкой `network`. **Скриншоты 4-5** Показать реализацию изображения по-умолчанию. **Скриншоты 6-7** Объяснить код компонентов для фильтрации, передаваемые props, **Скриншоты 8-9** все используемые хуки. **Скриншоты 10** `Readme` для фронтенда.

**Контрольные вопросы**: react, props и состояние, компонент и элемент, useState и useEffect, жизненный цикл компонента, Vite и Babel.

**Расчет аппаратных требований**: на 1 листе расчет аппаратных требований (число ядер, ОП, на 1 ядро по 4 ГБ ОП) по количеству пользователей и `rps`, а также требуемый размер жесткого диска с учетом прироста БД за 5 лет. Для расчета `rps` нужно взять количество команд RISC-V за день у одного пользователя, определить сколько HTTP `запросов` нужно выполнить для одной команды, поделить на рабочее время пользователей. Для прироста БД описать в байтах все поля таблиц команд RISC-V, а также объекты в `S3`. Расчет оформить формулами, в них указать ваши данные, а не общие переменные.

**Задание**: разработать три страницы фронтенд приложения на `React`, `TS` и подключить его к веб-сервису.

Разработать базовый интерфейс приложения на `React` для `гостя`, аналогичный двум страницам из лабораторной работы №1 для просмотра команд RISC-V: `лента` и `плитка`. При этом на странице `плитка` списка команд RISC-V должен быть фильтр по теме (по количеству операндов). Использовать компоненты `React-Bootstrap`. Для карточек предусмотреть изображение и видео по-умолчанию (в самом проекте), если поле в команде RISC-V пустое. Содержимое карточек получать только из коллекции с `mock`-объектами без бэкенда.

В приложении должны быть снизу навигационная панель `navbar` из 4 пунктов (лента, добавление, плитка, Вход). При этом только два пункта являются доступными. В этой лабораторной никакого `Redux`, а `Context` вообще в курсе использовать нельзя. В `README` описать страницы приложения с кнопками и полями на них.

## Страницы приложения

### Лента — `/riscv_commands/feed?id=<id>`

| Элемент | Описание |
|---|---|
| Видео команды | Воспроизводится автоматически; при пустом поле `video_url` — видео по умолчанию |
| Мнемоника | Название команды, например `ADD` |
| Описание | Две строки; кнопка «ещё» раскрывает полный текст, «меньше» сворачивает |
| Лайки | Число отметок «нравится» |
| Параметры | Количество операндов и длина команды в битах |
| Кнопка «Следующая команда» | Открывает следующую команду коллекции |

### Плитка — `/riscv_commands/grid?min_operands=<0–3>&max_operands=<0–3>`

| Элемент | Описание |
|---|---|
| Поле «Количество операндов» | Двойной ползунок от 0 до 3: минимум и максимум |
| Кнопка «Показать» | Применяет фильтр по количеству операндов |
| Карточка команды | Изображение (при пустом поле `image_url` — изображение по умолчанию), мнемоника, количество операндов, длина в битах и число лайков |
| Изображение карточки | Открывает команду в ленте |

### Нижняя навигация

| Пункт | Состояние |
|---|---|
| Лента | Доступен |
| Добавить | Недоступен |
| Плитка | Доступен |
| Вход | Недоступен |
